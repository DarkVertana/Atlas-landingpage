## 3. Crawl paths (internal linking)

- **Header:** logo→home; mega menus→services (9), how-it-works, trust, blog, faq,
  2 tools, about, contact, pricing (+ #whats-included, #comparison anchors);
  "Get Started"→/contact; mobile menu→6 top-level routes.
- **Footer:** 4 columns — Services (6), Company (5), Legal (6), Connect (4 social
  external links) + CRA disclosure + contact email/phone.
- **Cross-links:** service pages → pricing (#comparison), contact, blog posts;
  faq → terms/privacy/compliance/pricing/contact; CTASection (every page) →
  /contact.

## 4. Crawl budget notes

- 35 public routes total; 33 in sitemap — trivially small, all reachable in
  ≤3 clicks from the home page.
- `/admin` guarded by `proxy.ts` auth + robots disallow + noindex meta
  (triple protection).
- Blog posts render with `revalidate = 60` — ISR; sitemap picks up Supabase
  posts automatically via `getPublishedPosts()`.

## 5. Adding a page (process)

1. Create the route under `app/`.
2. Add a layout/page `metadata` export (title ≤60, description ≤155, FCRA-safe).
3. Add the route to `app/sitemap.ts` (static list) or let it flow via
   `getPublishedPosts()` for blog posts.
4. Wire it into Header/Footer menus if it's top-level.
5. Verify with `scripts/verify_seo.py` (H1, canonical, OG, JSON-LD, status).
